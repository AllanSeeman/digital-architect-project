
## Workflow: Sermon Repurposing Engine

**Required Skills:** [[Skill - Ministry Content Director]], [[Skill - Markdown Architect]]

### 🔹 PHASE 1: DATA CLEANUP & ARCHITECTING (MANDATORY)

**Action:** Before any analysis, invoke **[[Skill - Markdown Architect]]** to process the provided raw transcript text.

1. **Structural Reform:** Fix all PDF-related line breaks and join fragmented sentences.
    
2. **Theological Tagging:** Identify Scripture readings and place them in `> blockquotes`.
    
3. **Hierarchy:** Apply proper Markdown headers (`##`) for the Introduction, Main Points, and Conclusion.
    
4. **Validation:** Present the cleaned text in a code block and wait for the user to confirm they have replaced the raw text in their **Transcript Note** before proceeding.
    

### 🔹 PHASE 2: CONTEXT GATHERING

_Verify Speaker Name, Date, and specific Call to Action (CTA)._

### 🔹 PHASE 3: YOUTUBE OPTIMIZATION

_Generate 5 Viral-Style Titles, Description with Hook/Prayer/Keywords, and Timestamps._

### 🔹 PHASE 4: SOCIAL & EMAIL REPURPOSING

_Generate 3 Short-Form Video Scripts (30-60s) and a warm Email Newsletter Blurb._
